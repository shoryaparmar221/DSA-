# DSA

## About

DSA (Data Structures and Algorithms) is a Semester 3 repository containing notes, practice questions, and implementations of core DSA topics. It helps build strong problem-solving skills by understanding how data can be organized and processed efficiently.

## About DSA

Data Structures and Algorithms (DSA) is the study of organizing data and solving problems efficiently. Data structures such as arrays, strings, linked lists, and queues store data, while algorithms provide step-by-step methods to process it. Strong DSA knowledge improves logical thinking, coding skills, and performance in technical interviews.

## Topics Covered

| Topic | Description |

| Array |       A collection of elements stored in continuous memory and accessed using an index. 
| String |      A sequence of characters used to store and process text data. 
| LinkedList |  A linear data structure made of nodes, where each node points to the next node. 
| ArrayList |   A dynamic array that can grow or shrink in size as elements are added or removed. 
| Function |    A reusable block of code that performs a specific task when called. 
| Recursion |   A technique in which a function calls itself to solve a smaller version of the same problem. 
| Queue |       A linear data structure that follows the First In, First Out (FIFO) principle.
